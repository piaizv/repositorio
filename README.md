# repositorio

Se crea el repositorio en GitHub.

Se obtiene la url del repositorio: https://github.com/piaizv/repositorio.git

En el cliente se clona el proyecto vacío:

>git clone https://github.com/piaizv/repositorio.git

Como el proyecto está vacío, sólo se crea la carpeta .git.

Para publicar novedades:

>git add .

>git commit -m 'texto'

>git push

Se introducen las credenciales: cuenta de correo y token que se ha descargado.
