# repositorio

Se crea el repositorio en GitHub.

Se obtiene la url del repositorio: https://github.com/piaizv/repositorio.git.

En el cliente se clona el proyecto vacío:

>git clone https://github.com/piaizv/repositorio.git

Como el proyecto está vacío, se crea una carpeta con el nombre del repositorio, que
sólo contiene la carpeta .git.
Si se quiere usar con un proyecto ya creado localmente se puede
llevar el proyecto a la carpeta repositorio o se puede llevar
la carpeta .git de la carpeta repositorio a la carpeta principal del
proyecto creado localmente.

Para publicar novedades:

>git add .

>git commit -m 'texto'

>git push

Se introducen las credenciales: cuenta de correo y token que se ha descargado.
